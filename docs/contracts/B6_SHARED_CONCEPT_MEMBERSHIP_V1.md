# Shared Concept Membership V1

## 定位

Platform 发布“股票属于哪些同花顺概念”的中性共享事实。它不判断题材强弱，
不选股、不评分、不推送。当前消费者是 Shortline 09:25 扫描器。

## 生产合同

- 生产者：`yifei-platform-publish-concepts`。
- 上游：同花顺公开概念页面，分类口径固定为 `ths_concept`。
- 更新通道（2026-09-10 加固）：优先 `ths_public_json`，失败后使用原
  `ths_web` 浏览器通道；整份快照只选择一个通过质量门槛的通道，不拼接成分。
- 触发：`com.yplus.yifei-platform.concept-membership`，每周五 18:30；
  休市时以最近交易日作为 `trade_date`。
- 输出：
  `data/shared/concepts/{trade_date}/concept_membership_{trade_date}.json`。
- 合同版本：`platform-concept-membership.v1`。

快照保存来源、抓取时间、概念数量、各概念成分、完整概念比例和六位股票代码
解析率。同一日期的正式快照不可覆盖。

首次切换允许从原 Shortline 目录复制一份已通过同样完整性门槛的同日 `bootstrap`
快照。读取器只允许该 bootstrap 使用旧的 `shortline-concept-membership.v1` schema，
且只在标准文件尚不存在时使用它。Platform 标准文件一旦发布即取得优先级；旧
bootstrap 最多按下述 15 个交易日窗口复用，不形成第二生产链。

## 完整性与失败

发布门槛固定为：概念不少于 300、完整概念比例不低于 95%、股票代码解析率
不低于 98%。未达到门槛不发布新快照，也不混合其他概念体系。

消费者可读取最近成功快照：0—5 个交易日为 `normal`，6—15 个交易日为
`degraded`，超过 15 个交易日为不可用。复用是显式的新鲜度降级，不等于当周
概念已经更新。

### 通道与重试边界

- `ths_public_json` 复用 adata 所记录的 JSON 接口和 dragon-quant 的公开页面
  请求格式，不安装整套库：从 `http://q.10jqka.com.cn/gn/index/field/addtime/order/desc/page/1/size/1000/`
  的非 AJAX 完整表格取当日概念目录，从详情页核实原有六位概念代码、名称
  与八开头指数代码的映射，再从 `d.10jqka.com.cn/v2/blockrank` 获取成分。
  输出继续保留原概念代码，避免改变消费者的题材周期身份。
- 不把侧边导航当完整目录（2026-09-10 实测侧栏/首页合计仅 361 条，完整表格
  390 条）；拒绝剩余分页、重复目录行、缺失表格。HTTP 仅用于无凭据的公开
  q 站页面，与库原请求一致；JSON 成分仍走 HTTPS。此免费页面通道不是官方
  授权 API，不承诺无故障或完全独立容灾。
- JSON 通道每请求最多 3 次，暂时故障/空响应间隔 1、2 秒重试；单请求
  15 秒、整通道约 900 秒预算、最多 2 个并发，每概念间隔 0.25 秒。
  401/403/429 不反复重试，停止该通道剩余请求。不使用代理池、复制 Cookie
  或第三方共享账号。浏览器备用保留原有有限重试与执行超时。
- 首轮结束后，在同一个 900 秒预算内，对暂时请求失败的概念做一次串行恢复，
  每项间隔 1 秒；不重抓成功项，不对数量不符或身份冲突进行放宽。恢复次数和
  初次错误一并保留，拒绝访问时停止恢复；不存在无限重试或跨周悄悄拼接数据。
- 实际唯一成分数量必须等于来源声明总量；截断、无总量、无映射、名称冲突、
  拉取期间总量变化均不标记完整。浏览器路径也按声明总量核实完整性。
- HTML 的非数据区域出现坏编码时保留替代符，不因此丢弃整页；概念名称等
  实际事实字段含替代符仍拒收。JSON 按 UTF-8 严格解码，坏响应有限重试。
- 两条通道均依赖同花顺，且共享 q 站目录依赖，**不是完全独立容灾来源**。
  新通道小样本返回成功不代表全量更新已成功；以正式 `updated` 记录为准。
- 每次记录各通道成功/失败和实际发布来源。刷新失败但旧快照可用时，状态仍为
  `reused`，CLI 返回 3 并向 stderr 发出警告；完全不可用返回 2。
  `updated`、`already_current`、`skipped` 返回 0。此处警告进入既有运行日志，
  不代表新增了主动消息通知；卡片沿用原有快照年龄提示。
- 当天正式快照不可覆盖，不使用今天的新成分回填过去选股日期。最新成分抓取
  不能作为历史成分接口使用。

此次不接入 adata 的最多五页网页成分路径，也不接入 slingshot 的未通过访问
验证通道或 thsdk 默认第三方临时账号。不改变 Shortline 的规则、通知和归因。

## 边界

Platform 只负责事实生产、不可变保存和只读解析。Shortline 不得拥有概念采集器
或写入共享概念目录；它只能通过 Platform 的 `resolve_concept_snapshot` 读取。
